# T45 — Header and toolbars

**Goal:** Copy and Save move to the header, one callout toolbar serves every tab type, and Markdown gets a double-row text toolbar.

**Source:** `../../docs/collide-improvement-plan.md`, scope items 6.1 to 6.6 (Grant, 2026-11-18 to 2026-11-19); answers in `RUN4.md`. Nothing here is built yet: the app source is at the pre-coding state (`68af7b2`). Do not re-apply the reverted commits `f318f73` and `22352dc`; build from this scope.

**Files in scope:** `app/src/**`, `app/electron/**`, `app/e2e/**`, `app/e2e-electron/**`, tests. A new dependency needs a row in `PLAN.md` first.

**Acceptance criteria:**
- The toolbar grows and shrinks with the window; the scroll bar shows only when the window is too narrow for all icons (6.1).
- Markdown tabs use a double-row toolbar with the text tools on the second row; no text editing on PDFs or images (6.2).
- Copy to clipboard is in the header on every tab type and copies a PNG of the print area; on a PDF it copies the page nearest the centre of the view (6.3; Grant, 2026-11-19).
- Header Save buttons follow the Saved/Unsaved indicator: "Save source" saves a `.collide`; "Save as" saves PNG, JPEG, PDF for every tab and TXT, MD for Markdown tabs only. The save tools leave the callout toolbar (6.4).
- One callout toolbar on every tab type (6.5).
- Add border draws a coloured border around the main image's print area, like a rectangle callout; added images get none (6.6).
