# T06 — Save/open markup folder

**Goal:** Save writes a markup folder `source.png`, `annotations.json`, `export.png`; Open reads it back fully editable. Via Tauri fs (`@tauri-apps/plugin-fs`, `plugin-dialog`, approved in PLAN.md).

**Files in scope:** `app/src/io/**`, `app/src-tauri/**` (plugin registration, capabilities), toolbar Save/Open, tests.

**Acceptance criteria (from the board):** Reopened markup is fully editable and identical to what was saved.

**Planner notes:**
- Folder name `YYYY-MM-DD_<slug>` under a markups root (default `Documents/Collide/Markups` (A)); user picks with the dialog on Open.
- Put file access behind a small `MarkupStore` interface with a Tauri implementation and an in-memory one, so Vitest + Playwright (browser, no Tauri) can test round-trips. e2e: draw → save (memory store) → reload page → open → doc deep-equals and shapes are still selectable/movable.
- `export.png` uses T07's `flatten()` (T07 runs before T06 — see PLAN.md Order).
- Tauri capabilities: scope fs permissions to the markups root, not the whole disk.
- Reuse T07: `src/io/flatten.ts` (`flatten(stage, size)`, `dataUrlToBlob`, `exportFileName`) and the ds `Toast` for save/open errors (copy names cause + fix).
