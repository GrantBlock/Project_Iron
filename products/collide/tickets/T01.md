# T01 — Repo scaffold

**Goal:** Tauri v2 + React + TypeScript (Vite) app scaffold in `products/collide/app/`, with pnpm, ESLint, Vitest, Playwright and a `CLAUDE.md` for the app.

**Files in scope:** `products/collide/app/**` only.

**Acceptance criteria (from the board):** `pnpm tauri dev` opens an empty window; `pnpm test` and `cargo test` pass.

**Also required (Planner):**
- TypeScript strict mode. Scripts: `dev`, `build`, `test` (vitest run), `e2e` (playwright, against `vite preview`/dev server, chromium only, use preinstalled Playwright browser at /opt/pw-browsers if the pinned @playwright/test can't find it), `lint`, `tauri`.
- `src-tauri/` with a minimal `lib.rs` + one `cargo test`. Identifier `com.blockconcepts.collide`, product name `Collide`, window title `Collide`. App icons from `../design-system/assets/logo/` (never redraw).
- Empty window = a dark `--bg-canvas` page that imports `../design-system/styles.css` tokens; one smoke unit test and one smoke e2e test.
- `app/CLAUDE.md`: how to run dev/test/e2e/cargo test, folder layout, rules (design-system tokens only, no new deps without Planner).
- `.gitignore` for node_modules, dist, target.
