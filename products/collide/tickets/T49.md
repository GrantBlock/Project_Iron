# T49 — Markdown: one live editor (CodeMirror 6)

**Goal:** A Markdown tab has one view: the rendered page you type into directly, with the Markdown marks (`#`, `###`, `` ` ``, `:`, `**`, and so on) always visible, dimmed, with headings, bold and code styled around them. The Edit/Preview toggle goes away. The markup tools stay on the same page.

**Source:** Grant, 2026-11-20: "work directly in the preview", "see the text file notations", "use code mirror".

**Dependency (approved by Grant 2026-11-20):** CodeMirror 6 (`@codemirror/state`, `@codemirror/view`, `@codemirror/commands`, `@codemirror/lang-markdown`, `@codemirror/language`, MIT licence), pinned to the latest exact versions. Add a row to `PLAN.md` first. Nothing else new; `markdown-it` stays for the rendered output of Copy and Export.

**Files in scope:** `app/src/markdown/*`, `app/src/shell/*` where the tab mode is used, `app/package.json`, `PLAN.md`, tests, `app/e2e*`.

**Acceptance criteria:**
- One view: no Edit/Preview toggle. The text is edited in place; marks stay visible (dimmed), never hidden on other lines (A, Grant's words: always visible).
- Headings, bold, italic, code, lists, tables, links and block quotes are styled in place; undo and redo, selection, paste and IME input work as in CodeMirror.
- The text tools of the second toolbar row (Heading, List, Table, Label, Num list, Bold, Link) act on the selection or the line in the editor; Insert image and paste still save the picture into the zip's `images/` and link it at the caret.
- Callout markup stays where it was drawn, in page coordinates, when text above it changes (A, Grant to confirm); the tools, bubbles, cards and the list keep working on the page. Typing goes to the text when no drawing tool is active; a drawing tool draws on the page.
- Copy, Save as (TXT, MD, PNG, JPEG, PDF), Save source and the Saved/Unsaved indicator behave as before.
- Fit (Ctrl+0, F) and Ctrl + wheel zoom still work on the page.
