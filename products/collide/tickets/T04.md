# T04 — Drawing tools

**Goal:** Tools rect, ellipse, arrow, text, numbered callout; select, move, resize (Konva `Transformer`), delete. Shapes are the T02 model.

**Files in scope:** `app/src/editor/**`, `app/src/model/**` (only if needed), toolbar in `app/src/**`, tests.

**Acceptance criteria (from the board):** e2e draws one of each; resulting JSON matches expected types and bounds within ±2 px.

**Planner notes:**
- Toolbar per `design-system/ui_kits/snip-markup/Toolbar.jsx`: Select (V), Box (R), Ellipse (E), Arrow (A), Text (T), Callout (C), color swatches (signal, steel, + ink/white (A)), stroke width. Delete/Backspace removes selection.
- Drawing coordinates are image pixels (convert from stage via the zoom/pan transform), so bounds hold at any zoom.
- Callout = numbered steel badge (per readme: steel marks callout numbers) placed at click; number from `nextCalloutNumber`. Rect/ellipse/arrow also get a callout number as in the UI kit (A: matches the kit, where each markup adds a numbered callout).
- Selection look: 1px dashed white line, square corner handles (readme "Line work").
- Expose `window.__collide.getDoc()` returning the current annotations doc for e2e.
- Carry-over from T03 review: Space keydown must not preventDefault when a BUTTON (or other control) has focus, so toolbar buttons stay keyboard-operable.
- Wire the existing T03 toolbar (`src/editor/Toolbar.tsx`) rather than adding a second one; swatch colors from tokens.
