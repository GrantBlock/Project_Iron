# T02 — Shape model

**Goal:** TypeScript types + zod schema for `annotations.json`, covering `rect | ellipse | arrow | text | callout | highlight`, per SPEC.md "Data model and storage".

**Files in scope:** `products/collide/app/src/model/**` (+ tests).

**Acceptance criteria (from the board):** Save → load round-trip unit test; invalid JSON rejected with a clear error.

**Planner notes:**
- File shape: `{ version: 1, source: { kind: "image", width, height } , shapes: Shape[] }` (A) — a versioned wrapper around the spec's shape list so files can migrate later. Each shape has the spec's fields: `id, type, page?, x, y, w, h, stroke, strokeWidth, callout?, note?`; arrow also needs end points (`points: [x1,y1,x2,y2]` relative to x,y) (A); text needs `text`, `fontSize` (A).
- `serialize(doc): string` and `parse(json: string): Result` — parse never throws; errors read like the design-system voice: name the cause and the fix, include the JSON path (e.g. "shapes[2].w must be a number ≥ 0 — check annotations.json").
- Callout numbers: helper `nextCalloutNumber(shapes)`.
- Pixel coordinates for images; `page` optional (PDF later).
