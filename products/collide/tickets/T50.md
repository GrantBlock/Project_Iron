# T50 — Compact header buttons and a minimum window size

**Goal:** When the window gets small, the header buttons Save, Save source, Save as and Copy become icon-only, and the full app has a minimum window size that fits the current toolbars.

**Source:** Grant, 2026-11-20.

**Files in scope:** `app/src/shell/parts.tsx`, `shell.css`, `app/electron/main.cjs`, `app/src/native/*`, tests.

**Acceptance criteria:**
- Save, Save source, Save as and Copy show only their icon when the header is too narrow for their words. Each keeps its tooltip and accessible name (so existing tests that find them by name still pass). Close keeps its word (A). The switch is by the header's measured width, so open side panels count (A).
- The full app has a minimum window size, measured from the real layout: the smallest size at which the sidebar, the toolbar (tools, colours, thickness, undo and redo), the header and the callout panel fit without overlap or clipping. Report the numbers in ISSUES and TESTER-NOTES.
- The minimum applies to the full view only. The compact view (T48, 276 px wide) is smaller than it, so the minimum is lifted on collapse and restored on expand.
