# T08 — Rust capture_monitor

**Goal:** Tauri command `capture_monitor` that captures the monitor under the cursor with the `xcap` crate and holds the frozen frame in app state (Tonight's default: monitor under the cursor only).

**Files in scope:** `app/src-tauri/src/**`, `app/src-tauri/Cargo.toml`.

**Acceptance criteria (from the board):** Returns PNG with monitor dimensions; error path tested when capture fails.

**Planner notes:**
- Put capture behind a `Capturer` trait (real: xcap; fake: returns a fixed RgbaImage or an error) so `cargo test` runs headless. Store `{ image, monitor: { x, y, width, height, scale_factor } }` in a `Mutex` in managed state.
- Cursor position: xcap's `Monitor::from_point` with the cursor point; get the cursor via Tauri's `cursor_position()` on the app/window (A) — no new crate.
- Command returns `{ width, height, x, y, scaleFactor, png: base64 or a file path }` (A: base64 data URL is fine for Phase 2; note size).
- Errors are a typed enum serialized to a message that names cause and fix (e.g. "Screen capture failed — check screen recording permission and try again.").
- Tests: fake capturer → PNG decodes to monitor size; failing capturer → error variant and state unchanged.
