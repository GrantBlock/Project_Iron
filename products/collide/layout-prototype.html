Collide: Snip and Zip editor

  1. No chat in Collide (Grant 2026-11-15). Agents are worked on separately; Agent Chat (tools/project-chat) stays its own app.
  2. Home is a blank canvas with Recents on the left: snips, zip files and their folder trees, tags.
  3. Tabs on the canvas (Grant 2026-11-15): each open snip, file or Settings is a tab with a dot: amber = changed, green = saved. Each keeps its own undo and zoom. Ctrl+W or × closes, Ctrl+Tab switches, middle-click closes.
  4. Closing with unsaved changes shows a splash screen: Save and close, Close without saving, Cancel.
  5. Markdown files: Preview with Callouts, or Code + preview. Box and Circle callouts on the page; Canvas snip saves the marked-up area as a markup.
  6. Collapse moves Recents to the right. Windowed: the window shrinks to Recents; a new or opened snip adds a canvas and fits to it. Maximized: blank canvas. Try both with the "Prototype · window" switch.
  7. Storage on the server PC, with automatic deletion after [number of files]. Settings → Storage.
  8. Themes: Dark, Light, Aura for the whole app. The logo is never recoloured.
