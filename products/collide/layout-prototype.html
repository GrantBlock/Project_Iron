Collide: Snip and Zip editor

  1. No chat in Collide (Grant 2026-11-15). Agents are worked on separately; Agent Chat (tools/project-chat) stays its own app.
  2. Home is a blank canvas with Recents on the left: snips, zip files and their folder trees, tags. Hover a snip or zip and click the bin (or press Delete) to delete it; a splash screen asks first.
  3. Tabs on the canvas (Grant 2026-11-15): each open snip, file or Settings is a tab with a dot: amber = changed, green = saved. Each keeps its own undo and zoom. Ctrl+W or × closes, Ctrl+Tab switches, middle-click closes.
  4. Closing with unsaved changes shows a splash screen: Save and close, Close without saving, Cancel.
  5. Markdown markup = image markup (Grant 2026-11-15): the same tools, note bubbles with angled leaders (outside the page, stacking and snapping), and the same callout cards. New tools go to both.
  6. Markdown files: Edit (Markdown with a live preview) or Preview (mark up), switched in the header; "● unsaved" beside the name; Save; full width (square) hides the sidebar and callouts; ^ hides the toolbar. Edit toolbar: Heading ▾, List, Table, Label, Num list, Bold, Link, Insert snip; tables show in the preview. The markup toolbar uses the Snip layout: Select, Box, Circle, Line, X mark, Point, 4 colours, stroke 2/3/5; Insert image sits with the tools; on the right, like the image editor: undo/redo, Copy and Export (saves the visible page as a markup). Canvas snip is removed. Resize handles and Delete work as in Snip. Copy PNG copies the visible page with its callouts; Canvas snip saves a marked-up area as a markup. Both stay inside the visible area.
  7. Collapse moves Recents to the right. Windowed: the window shrinks to Recents; a new or opened snip adds a canvas and fits to it. Maximized: blank canvas. Try both with the "Prototype · window" switch.
  8. Storage on the server PC, with automatic deletion after [number of files]. Settings → Storage.
  9. Themes: Dark, Light, Aura for the whole app. The logo is never recoloured.
